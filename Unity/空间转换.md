# Unity Shader 内置空间转换与矩阵总结

> [!abstract] 核心概念
> 在 Shader 中，**位置（Position）** 和 **方向（Direction）** 是基础。所有的矩阵和函数都是为了把它们在不同的“空间”里搬来搬去，以满足渲染或光照的需求。

## 一、 两个高频核心变量

* **`pos_world` (世界空间位置)：**
  * **本质：** 一个具体的坐标点 $(x, y, z)$。
  * **受限：** 受模型的平移、旋转、缩放影响。
  * **用途：** 计算距离（雾效、光照衰减）、世界空间特效（扫描线、基于高度的积雪）。
* **`normal_world` (世界空间法线)：**
  * **本质：** 一个代表表面朝向的向量（方向）。
  * **受限：** 仅受旋转和不均匀缩放影响，**不受平移影响**。
  * **用途：** 光照计算（最核心）、环境反射、边缘发光（Rim Light）。

---

## 二、 核心转换矩阵 (MVP 家族)

这些内置矩阵是不同空间之间的“传送门”。

| 矩阵变量名 | 代表字母 | 转换路径 (从 ➔ 到) | 核心作用 |
| :--- | :--- | :--- | :--- |
| `unity_ObjectToWorld` | **M** (Model) | 模型空间 ➔ 世界空间 | 将局部坐标转换为世界绝对坐标 |
| `unity_WorldToObject` | M 的逆矩阵 | 世界空间 ➔ 模型空间 | 将世界坐标转回模型自身坐标 |
| `UNITY_MATRIX_V` | **V** (View) | 世界空间 ➔ 观察空间 | 转换为以相机为中心的相对坐标 |
| `UNITY_MATRIX_P` | **P** (Projection) | 观察空间 ➔ 裁剪空间 | 准备压扁为 2D 屏幕图像 |
| `UNITY_MATRIX_VP` | VP 结合 | 世界空间 ➔ 裁剪空间 | 跨过观察空间，直接转到裁剪空间 |
| `UNITY_MATRIX_MVP` | MVP 结合 | 模型空间 ➔ 裁剪空间 | 顶点着色器中最经典的“一步到位”转换 |

> [!warning] 矩阵乘法顺序
> 在 CG/HLSL 中，通常是矩阵在左，向量在右：`mul(矩阵, 向量)`。

## 三、 官方封装的高效函数 (强烈推荐)

在实际编写中，建议优先使用 `UnityCG.cginc` 提供的内置函数，它们不仅写起来简短，还在底层处理了很多数学边缘情况。

### 1. 顶点与位置转换
* **`UnityObjectToClipPos(v.vertex)`**
  * **作用：** 等同于乘 MVP 矩阵，将顶点直接从模型空间转到裁剪空间。现代 Unity 强烈推荐的最高效写法。
* **`UnityObjectToWorldDir(v.vertex)`**
  * **作用：** 将方向向量从模型空间转换到世界空间。

### 2. 法线转换
* **`UnityObjectToWorldNormal(v.normal)`**
  * **作用：** 把模型法线转到世界空间。
  * **避坑指北：** 不要直接用矩阵乘法算世界法线！当模型发生**非等比缩放**时，直接乘矩阵会导致法线变形。该函数内部使用了逆转置矩阵，确保法线永远正确垂直于表面。

### 3. 光照与视线方向
* **`UnityWorldSpaceLightDir(worldPos)`**
  * **作用：** 传入顶点的世界坐标，获取该点到光源的方向向量（注意：计算光照前需手动 `normalize()`）。
* **`UnityWorldSpaceViewDir(worldPos)`**
  * **作用：** 传入顶点的世界坐标，获取该点到相机的视线方向向量。

## 四、 空间转换流水线 (Mental Model)

理解 3D 模型是如何一步步显示到屏幕上的，按顺序经历以下四步：

1. **模型空间 (Model Space)：** 建模软件中的原始局部坐标。
2. **世界空间 (World Space)：** 游戏场景里的绝对坐标（光照计算的主战场）。
3. **观察空间 (View Space)：** 相机的第一人称主观视角，深度计算（Z值）常在这里进行。
4. **裁剪空间 (Clip Space)：** 剔除视野外的画面，准备输出到 2D 屏幕。

## 五、 TRANSFORM_TEX：处理 UV 的缩放与偏移

在 Unity 的材质球（Material）面板上，每当你贴上一张贴图（比如 `_MainTex`），下面通常都会自带两行参数：
*   **Tiling (X, Y)：** 控制贴图的重复缩放。
*   **Offset (X, Y)：** 控制贴图的平移滑动。

`TRANSFORM_TEX(v.uv, _MainTex)` 就是用来激活这两个参数的内置函数（严格来说它是一个宏）。
