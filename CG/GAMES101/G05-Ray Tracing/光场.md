## 1. 核心定义
光场是空间中**所有光线的集合**。
* **传统图像**：只记录了光线打在平面上形成的“颜色总量”（丢失了方向信息）。
* **光场**：记录了每一条光线从哪里来，朝哪个方向去。

## 2. 物理基础：全光函数 (Plenoptic Function)
为了描述空间中所有的光，引入了全光函数：
$$L = P(x, y, z, \theta, \phi, \lambda, t)$$

| 参数 | 含义 |
| :--- | :--- |
| (x, y, z) | 空间坐标（位置） |
| (θ, φ) | 传播方向（角度） |
| λ | 波长（颜色） |
| t | 时间（动态） |

> **物理学假设**：基于几何光学，光在介质中沿直线传播。

## 3. 数学简化：双平面参数化 (Two-Plane Parameterization)
为了将复杂的 7D 函数降维以便计算机处理，常用的方法是在两个平行平面（UV 平面和 ST 平面）之间对光线进行采样。
* 任何一条穿过这两个平面的光线，都可以由其在两个平面上的交点坐标 $(u, v)$ 和 $(s, t)$ 唯一确定。
* **本质**：为空间中的每一条光线建立“身份证号”。

## 4. 技术美术 (TA) 的应用关联
理解光场是进阶渲染管线的基石，常见的应用场景包括：

* **环境光照 (Global Illumination)**：
    * **Light Probe / Reflection Probe**：本质是空间某一点的光场采样，用于模拟间接光照与环境反射。
* **现代 AI 渲染技术**：
    * **NeRF (神经辐射场)**：通过神经网络拟合全光函数，从多张照片重建 3D 场景的光场。
    * **3D Gaussian Splatting**：高效表示与渲染光场信息的技术。
* **光线追踪 (Ray Tracing)**：
    * 模拟光线在场景中的传播路径，即主动计算光场信息，以解决传统光栅化无法处理的遮挡与间接光问题。

## 5. 学习总结
作为 TA，不需要深入研究纯学术的物理公式，但必须建立**“光线不仅仅是颜色，还是方向向量”**的直觉。当你看到任何有关“反射探针”、“射线追踪”或“视角相关渲染”的技术时，其底层逻辑都是在处理光场信息。
