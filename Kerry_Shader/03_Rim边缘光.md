## 一、 涉及到的效果

本 Shader 主要用于实现“X光透视”、“幽灵材质”、或是“纯粹的能量发光体”效果，具有以下视觉特征：

- **核心透明，边缘发光**：物体正中心完全看不见（透明），只有轮廓边缘会发出亮光。

- **指数级光晕控制**：可以通过调节参数，让边缘的发光像细丝一样锐利，或者像雾气一样柔和。

- **加法发光叠加**：利用 Blend SrcAlpha One 混合模式，使得重叠在一起的发光体会变得更亮，非常适合做纯能量体。

- **双面渲染控制**：可以在材质面板直接下拉选择剔除模式（CullMode），决定是只显示正面、只显示背面，还是双面都显示。


## 二、 核心数学原理

1. 指数衰减函数 (Power Falloff)


- **原理**：上一节代码中，光晕的粗细是用 smoothstep 截断出来的。而这份代码使用了更符合自然物理衰减的幂函数 pow()。

- **公式**：

$$f(x) = x^n$$

- **代码**：pow(1.0 - NdotV, _RimPower)。

	这里的 $x$ 是基础的边缘光强度（$0 \sim 1$），$n$ 就是面板上的 _RimPower。当 _RimPower 大于 $1$ 时，原本较弱的光（零点几）自乘后会变得更小，这意味着发光区域会被向外挤压，光边变得更细、更锐利。


2. 局部空间到平面投影 (Planar Mapping)


- **原理**：代码中并没有使用模型美术做好的标准 UV，而是强行提取了模型顶点的 X 和 Z 坐标来当做 UV。

- **代码**：float2 xz_uv = v.vertex.xz;

- **意义**：这相当于从物体的正上方往下打一束投影，把贴图印在模型上。这种技术常用于地形材质，或者需要与世界水平面强绑定的扫描特效。


## 三、 逻辑架构

代码结构非常精简，主要分为以下模块：

1. Properties (属性面板)


定义了暴露给 Unity 材质面板的参数：

- _MainTex：主贴图（虽然定义了，但在最终上色时被忽略了）。

- _MainColor & _Emiss：控制发光的基础颜色和整体亮度倍率。

- _RimPower：核心控制参数，控制边缘光晕的厚度和硬度。

- _CullMode：利用 [Enum] 属性标签，在面板生成一个下拉菜单，暴露渲染管线的剔除状态。


2. 顶点着色器 (Vertex Shader)


核心任务：空间转换与视线向量预计算。

- **坐标转换**：将顶点从 Local 转换到 Clip 空间。

- **法线转换**：将法线转入世界空间 UnityObjectToWorldNormal(v.normal)。

- **性能优化点**：直接在顶点阶段就算好了视线方向 view_world，而不是留给片元着色器去算，这节省了每个像素的计算量。

- **自定义 UV**：计算基于 XZ 平面的 UV 投影坐标。


3. 片元着色器 (Fragment Shader)


核心任务：计算最终的发光颜色与透明度。

- **向量归一化**：对顶点传过来的法线和视线进行 normalize。

- **点乘与菲涅尔**：计算 dot(N, V)，并用 pow 函数算出最终的发光比例 fresnel。

- **颜色输出**：最终颜色是纯色乘以亮度（_MainColor * _Emiss），而该像素的 Alpha 透明度由算出的 fresnel 决定。


## 四、 代码实现难点与坑点

Blend SrcAlpha One 与透明度通道的关系

- **难点**：代码最后返回了 float4(col, rim)，这里的 rim 被放在了 Alpha (透明度) 通道。

- **解析**：由于开启了 Blend SrcAlpha One，渲染公式为 最终颜色 = 算出的颜色 * 算出的Alpha + 背景颜色 * 1。这意味着，Alpha 通道在这里并不是用来做传统半透明的，而是作为一个“发光强度系数”。rim 为 $0$ 的地方（模型中心），完全不添加颜色；rim 为 $1$ 的地方（边缘），将颜色完全加在背景上。


渲染状态枚举 [Enum(UnityEngine.Rendering.CullMode)]

- **难点**：在属性里写代码控制渲染管线状态。

- **解析**：这是一个高级的 Shader 写法。通常 Cull Off 等命令是写死的，但通过定义 [_CullMode] 变量并绑定到属性面板的内置枚举类，可以让使用者在编辑器里灵活切换双面/单面显示，非常适合做幽灵、披风等需要正反面发光的需求。


【发现代码盲区】：计算了 UV 却未使用

- **难点分析**：在 Vertex 阶段，费力计算了平面投影的 UV o.uv = xz_uv * _MainTex_ST.xy + _MainTex_ST.zw;，并且在 Fragment 阶段也声明了 sampler2D _MainTex;。但是，frag 函数中根本没有使用 tex2D 去采样这张贴图！

- **结论**：这是一个常见的“遗留代码”或“开发中代码”。最终呈现的效果完全是一个纯色发光体（由 _MainColor 决定），如果你想让贴图生效，需要在 frag 中添加 half4 texColor = tex2D(_MainTex, i.uv); 并将其乘到最终的 col 里面。
