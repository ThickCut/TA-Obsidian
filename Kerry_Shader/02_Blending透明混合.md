## 一、 涉及到的效果

本 Shader 主要用于实现基础的**加法发光贴图**、**地面法阵**或**简单的全息投影**，具有以下视觉特征：

- **加法发光混合**：使用 Blend SrcAlpha One 混合模式，贴图上越亮的地方叠加在背景上越耀眼，纯黑的地方完全透明。

- **自上而下的平面投影**：不依赖模型本身美术做好的 UV 展开，而是直接从物体的正上方（Y轴）往下投射贴图，非常适合做地表的魔法阵或扫描底座。

- **双面显示**：支持通过面板自由切换剔除模式（单双面显示）。

## 二、 核心数学原理

1. 空间转换的“前世今生”（MVP 矩阵转换）

代码的顶点着色器中保留了很长一段被注释掉的代码，这展示了图形学中最著名的**MVP矩阵变换**全过程：

- **第一步 (Model)**：将顶点从模型本地转换到世界空间 `mul(unity_ObjectToWorld, v.vertex)`

- **第二步 (View)**：将世界坐标转换到摄像机的观察空间 `mul(UNITY_MATRIX_V, pos_world)`。

- **第三步 (Projection)**：将观察空间坐标投影到屏幕的裁剪空间 `mul(UNITY_MATRIX_P, pos_view)`。

在较新的 Unity 版本中，直接被封装成了一个性能更高的 API：`UnityObjectToClipPos(v.vertex)`。


2. 向量的自由重组 (Swizzle 操作)    

- **原理**：在 Shader 语言（HLSL/CG）中，一个包含 4 个小数的向量（如 `float4`）可以通过 `.xyzw` 或 `.rgba` 来访问。更强大的是，你可以随意改变它们的顺序组合。

- **代码体现**：代码中提取颜色的写法是 `_MainColor.xwz`。这在数学上等同于把原本的 $(X, Y, Z)$ 变成了 $(X, W, Z)$，也就是提取了原颜色的**红、透明度、蓝**组合成了新的颜色。

## 三、 逻辑架构

1. Properties (属性面板)


- _MainTex：主贴图，在这里实际上作为**发光形状的遮罩**来使用。

- _MainColor & _Emiss：控制发光颜色与发光强度倍率。

- _CullMode：暴露剔除模式，方便调整单双面。


2. 顶点着色器 (Vertex Shader)


- **顶点位置转换**：使用 `UnityObjectToClipPos` 将模型塞进屏幕。

- **局部 XZ 平面 UV**：提取模型本地坐标的 `x` 和 `z` 作为平面的长宽坐标。

- **应用 Tiling 与 Offset**：`xz_uv * _MainTex_ST.xy + _MainTex_ST.zw`。这是 Unity 中使材质面板上的 Tiling（缩放）和 Offset（偏移）参数生效的标准数学公式。


3. 片元着色器 (Fragment Shader)


- **提取颜色**：获取属性面板的颜色并乘以发光倍率 `_Emiss`。

- **提取透明度**：由于是发光材质，代码并没有使用贴图的 Alpha 通道，而是采样了贴图的红通道（r）作为基础透明度：`tex2D(_MainTex, i.uv).r`。然后将其与面板颜色的透明度、发光倍率相乘，最后用 saturate 截断在 $0 \sim 1$ 之间。

- **输出**：返回最终的颜色和算出的透明度。

## 四、 代码实现难点与坑点

坑点 1：奇怪的 `_MainColor.xwz`（可能是笔误）

- **分析**：正常提取颜色的 RGB 通道，应该写 `_MainColor.xyz`（或 `.rgb`）。但这里写成了 `.xwz`。

- **结果**：`w` 代表第四个通道（即 Alpha 透明度）。这就导致面板上选择颜色的**绿色通道完全失效**，取而代之的是，你拉动面板上的 Alpha 滑块，会改变物体发光颜色的绿色部分。这极大概率是原作者编写代码时手指打滑按错了键盘（W 和 E/Y 很近，或者纯粹的思维短路）。


坑点 2：冗余的变量声明

- **分析**：在 `v2f` 结构体中声明了 `float2 pos_uv : TEXCOORD1;`，在顶点着色器中也为它赋了值 `o.pos_uv = v.vertex.xz;`。但是，在最终的片元着色器 `frag` 里，根本没有使用 `i.pos_uv` 这个变量。

- **结论**：这是典型的开发中残留的冗余代码，会白白占用一点点在顶点和片元之间传递数据的带宽，在项目优化阶段应当删除。


核心设计思维：用黑白图做遮罩

- **思维转变**：在这段代码中，`_MainTex` 并不是用来“展示五颜六色的图片”的。开发者取了它的 `.r` 通道当做透明度（Alpha），这意味着：贴图里红色的部分会发光显示，没有红色的部分（如纯黑）会完全透明。这在特效制作中被称为“遮罩图 (Mask)”思维。
